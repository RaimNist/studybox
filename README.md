# StudyBox

## Работа с приложением

1. Откройте папку `studybox`.
2. Откройте `index.html` в браузере.
3. Выполните подготовленные тест-кейсы.
4. Записывайте Actual Result для каждого тест-кейса.
5. Ставьте Pass или Fail, сравнивая фактический результат с ожидаемым.

Приложение работает локально.
Данные формы никуда не отправляются и не сохраняются.
